# かがわ進路コンパス

香川県の人材流出(大学進学を機に県外へ出て戻らない問題)を防ぐための、高校生・進路指導教員向けWebアプリです。

成績への不安や「やりたいことが香川にはない」という思い込みから県外進学を決める前に、興味・関心に基づく県内大学とのマッチング診断、実データに基づく香川のキャリア紹介、奨学金・支援制度の情報、そしてAIとの対話を通じて、香川に残るという選択肢を根拠を持って検討できるようにすることを目的としています。

## 構成

- `index.html` — アプリ本体(単一HTMLファイル、外部依存なし)
- `docs/lean-canvas.pptx` — このプロジェクトのリーンキャンバス(企画資料)

## 主な機能

1. **AI進路相談**(トップ導線) — Claudeとの対話形式で、大学・奨学金・香川での仕事・10年後の理想の自分について相談できます。
2. **大学マッチング診断** — 10問の質問から、香川県内の大学・学部との関心マッチ度を診断します。
3. **香川で叶うキャリア** — 香川県内の実在企業・産業を分野別に紹介します。
4. **先輩の声** — 分野ごとのイメージを伝える、架空のモデルケースです。
5. **奨学金・支援制度** — 香川県が実施する奨学金・移住/就職支援制度をまとめています。

## AIチャット機能について(重要)

「AI進路相談」タブは、Claudeの Artifact 実行環境が提供する `sample` / `downloads` capability を利用しています。これは **claude.ai 上でこのページを開いた場合にのみ動作します**。GitHub Pages など、Claudeの外でこの `index.html` をホストした場合、AIチャット機能は自動的に「この表示環境では利用できません」という案内に切り替わり、他の4機能(診断・キャリア・声・支援制度)は問題なく動作します。

ネイティブアプリ化や、Claude外での本格運用を検討する場合は、AIチャット部分を自前のAnthropic API連携(バックエンド経由)に置き換える必要があります。

## データについて

大学・産業・奨学金の情報は、公開されている一次情報(各大学・香川県の公式サイト等)を調査して作成した参考情報です。定員・偏差値など確認できなかった項目は「不明・要確認」としており、正式な出願・申請前には必ず各公式サイトで最新情報をご確認ください。
