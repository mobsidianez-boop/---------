# かがわ進路コンパス

香川県の人材流出(大学進学を機に県外へ出て戻らない問題)を防ぐための、高校生・進路指導教員向けWebアプリです。

成績への不安や「やりたいことが香川にはない」という思い込みから県外進学を決める前に、興味・関心に基づく県内大学とのマッチング診断、実データに基づく香川のキャリア紹介、奨学金・支援制度の情報、そしてAIとの対話を通じて、香川に残るという選択肢を根拠を持って検討できるようにすることを目的としています。

## 構成

- `index.html` / `style.css` — アプリのマークアップとスタイル(外部依存なし)
- `intro.js` — 起動時イントロ演出
- `data.js` — 大学・産業・奨学金・診断データなど、アプリが表示する「中身」
- `tabs.js` — メインナビゲーション(タブ)の切り替え
- `quiz.js` — 大学マッチング診断のロジック
- `content.js` — 「香川で叶うキャリア」「奨学金・支援制度」タブの表示
- `schedule.js` — 「予定表」タブ(生徒が自分で作る個人スケジュール)の機能
- `chat.js` — 「AI進路相談」タブ(Claudeとのチャット・プロフィールカード)
- `docs/lean-canvas.pptx` — このプロジェクトのリーンキャンバス(企画資料)

チームでの分担作業をしやすくするため、機能ごとにファイルを分割しています。`index.html` は上記のJSファイルを`<script>`タグで順番に読み込む構成です。

## 主な機能

1. **AI進路相談**(トップ導線) — Claudeとの対話形式で、大学・奨学金・香川での仕事・10年後の理想の自分について相談できます。会話はこの端末のブラウザ内(localStorage)に保存され、次回開いたときも続きから話せます。
2. **大学マッチング診断** — 10問の質問から、香川県内の大学・学部との関心マッチ度を診断します。診断結果は印刷用サマリー(教員・進路指導室向け)としてそのまま印刷できます。
3. **香川で叶うキャリア** — 香川県内の実在企業・産業を分野別に紹介します。
4. **奨学金・支援制度** — 香川県が実施する奨学金・移住/就職支援制度をまとめています。
5. **予定表** — 生徒が自分で予定を作る、丸でつながる「トレイル」形式のスケジュール機能です。月の丸→週の丸→曜日、の順にタップして「やること」を書き込みます。月ごとに「大きな目標」も設定できます。1週間は月曜始まり・日曜終わりで、月をまたぐ週は日曜日が含まれる月の方に表示されます。過ぎた日には追加できません。入力データはこの端末のブラウザ(localStorage)にのみ保存されます。

## AIチャット機能について(重要)

「AI進路相談」タブは、Claudeの Artifact 実行環境が提供する `sample` / `downloads` capability を利用しています。これは **claude.ai 上でこのページを開いた場合にのみ動作します**。GitHub Pages など、Claudeの外でこの `index.html` をホストした場合、AIチャット機能は自動的に「この表示環境では利用できません」という案内に切り替わり、他の4機能(診断・キャリア・支援制度・スケジュール)は問題なく動作します。

ネイティブアプリ化や、Claude外での本格運用を検討する場合は、AIチャット部分を自前のAnthropic API連携(バックエンド経由)に置き換える必要があります。

## データの更新について

大学・産業・奨学金・入試スケジュールの情報は、公開されている一次情報(各大学・香川県の公式サイト等)を調査して作成した参考情報です。各タブの「📌 情報基準日」表示で、その情報をいつ確認したかを明示しています。年度が変わると募集要項・定員・日程が更新されるため、正式な出願・申請前には必ず各公式サイトで最新情報をご確認ください。

なお、`SCHEDULE`(入試・奨学金の固定データ)を使った自動更新は、予定表が生徒自身が作る個人スケジュールに変わったことに伴い使われなくなりました。毎年6月頃に公式サイトの情報を確認・更新するスケジュールタスクを設定していた場合は、チームで扱いを見直してください。
